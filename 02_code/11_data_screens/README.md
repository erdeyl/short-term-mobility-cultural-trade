# Data screens (not run by run_all.py)

`SW2_01` … `SW2_09` are the screening scripts behind the data-quality flags in `derived/flags/sweep2_*.csv`: parsing of the UN Tourism workbooks, partner sums against published totals, residence–nationality comparisons, basis switches, year-on-year jumps, visitor–tourist hierarchy, code mapping, and trade-side screens (reporter-year totals, pair-year outliers, unit values, mirror comparison). They read the raw files of `01_raw/`, the UN Tourism bulk download (`01_raw/09_UN_Tourism_bulk/Bulk/…`, not in the manifest), the common-base intermediates and `05_output/10_analysis/<vintage>/prepared.dta`, and write to `05_output/11_data_screens/`. Their findings were turned into the quarantine rules and sensitivity flags documented in `README.md`, Section 6; the estimates use the flags as written out in `02_code/10_analysis/C2_A1_07_sweep2.do`, so these scripts are not needed to reproduce any table.
