# Contents of the replication package

| Folder or files | Content |
|---|---|
| `README.md` | purpose, run order, outputs, table/figure and reviewer-request maps, data-correction rules, software, limitations |
| `CONTENTS.md` | this list |
| `VALIDATION.md` | clean-room run of the final code: comparison of the produced tables, figure data and estimate files with the reported results, scope of the run (final data version; what it does not run), exhibit-level accounting, run times |
| `LICENSES_AND_SOURCES.md` | data providers' terms (quoted, with URLs and access dates) and what the package ships |
| `LICENSE`, `LICENSE-CC-BY-4.0.md` | MIT License for the code; CC BY 4.0 for the documentation and the derived key files |
| `run_all.py` | single entry point: stages check, build, analysis, results |
| `requirements.txt` | pinned Python modules with hashes |
| `install/` | Stata package installation (network) and exact-version check |
| `01_raw/` | `RAW_MANIFEST.sha256` (SHA-256 of the 1,100 raw files used), `README.md` per source with retrieval instructions; included: World Bank income classifications, CEPII Language database |
| `02_code/00_acquisition/` | UN Comtrade API acquisition scripts (importer-reported files) |
| `02_code/00_common/` | common base: UN Comtrade cultural trade, HS concordance, CEPII Gravity variables |
| `02_code/03_Mobility/` | Mobility data build (UN Tourism, Hofstede, master panel, analysis inputs, exporter-reported mirror) and the original estimation do-files |
| `02_code/99_rescue/` | data-correction switch and modules, sample-size log command, Stata launcher shim |
| `02_code/10_analysis/` | analysis of the revision: data preparation (`00_config.do`, `01_prep.do`), positive controls (`02_*`), estimates (`A1_*`, `A2_*`, `C2_*`), the same stacked tests with unordered-pair clusters (`UP_*.do`, generated by `C2_A1_12_make_upair.py`; paired by `C2_A1_12_upair_table.py`), tables (`TAB_*`, `C2_TAB_build.py`), figures (`FIG_*`), helpers (`pkg_*`) |
| `02_code/11_data_screens/` | data-quality screening scripts behind the flag lists (not run by default) |
| `derived/products/` | HS six-digit product list with basket memberships; UNESCO FCS 2009 benchmark codes |
| `derived/concordance/` | reported HS edition and code to HS 2007 concordance with the ambiguity classification |
| `derived/flags/` | estimation-sample and quarantine flags (keys and 0/1 flags only); importer-years without archived rows; data-quality screen results |
| `derived/worldbank/` | World Bank region and income group by economy and year |
| `derived/hofstede/` | Hofstede code map, unmapped rows, regional-proxy construction (no scores) |
| `derived/table_templates/` | table layout of the submitted manuscript |
| `tools/` | raw-file verification, portability scan, output comparison, rebuild of the Hofstede sheet from the official file, anonymized-release builder and check |
| `06_results/tables/final/` | table files `Table1`–`Table7` (layout of the submitted tables; crosswalk to the revised numbering in `README.md`, Section 3) and `TableA1`–`TableA5` (CSV); Supplementary Table S2.7 (economies and years per sample) |
| `06_results/figures/` | Figure 1 (mobility slopes over cultural distance) and Figure 2 (coefficient plot): PDF, PNG and the plotted data (CSV); the code also writes 600-dpi TIFF files |
| `05_output/` | run logs, run times, estimate files and control files of the clean-room run (released subset); `05_output/10_analysis/corrected2x_upair/` holds the estimates of the `UP_*.do` copies (unordered-pair clusters) |
