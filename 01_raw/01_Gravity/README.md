# CEPII Gravity database, version V202211

Files: `Gravity_V202211.dta`, `Countries_V202211.dta` (place both in this folder).

1. Download the Stata version from the CEPII database page (https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=8; this is the 202211 version): https://www.cepii.fr/DATA_DOWNLOAD/gravity/data/Gravity_dta_V202211.zip
2. Unzip and place the two `.dta` files here. Their SHA-256 must equal:
   - `Gravity_V202211.dta`: `e231c2756ac69b25960f4b0aa93f6bbf3c225e40a8b6f9ecfe5dea8c36b49447`
   - `Countries_V202211.dta`: `6db32511afb0faf07d5d51c0ecd80d4fdcb590d84d9263865f8a2bb9d4323797`

That `Countries_V202211.dta` is part of the zip was not verified from the provider's page; if it is not, obtain it from the same page.
